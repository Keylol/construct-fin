# Роли: владелец и оператор

Дата: 2026-09-07. Приложение — один бизнес, в нём два человека: **владелец**
(он же разработчик) и **оператор** (сотрудник, который вносит заказы и
операции). Экран входа один, пароля два; кто вошёл — решает совпавший хэш.

| | Владелец | Оператор |
|---|---|---|
| Переменная | `AUTH_PASSWORD_HASH` | `OPERATOR_PASSWORD_HASH` |
| Пользователь | синтетический `telegramId=1` | синтетический `telegramId=2` |
| Роль в пространствах | `OWNER` | `MEMBER` во **всех** живых пространствах (членство досоздаётся при каждом входе) |
| Меню | всё | без технических разделов (Правила, Переводы, Импорт, Интеграции, Сверка, Здоровье, Аудит) и настроек справочников (Счета, Контрагенты, Категории); прямой адрес отвечает «Раздел недоступен» |
| Удаление / отмена | да | **нет** — проверяется на сервере |

## Что именно закрыто оператору на сервере

`WorkspaceGuard` (`apps/api/src/common/workspace.guard.ts`) после проверки
членства спрашивает `deniedForRole` (`common/role-policy.ts`):

- любой `DELETE` (заказы, операции, платежи заказа, закупки, вложения,
  справочники, партии импорта, бюджет, планы);
- обработчики с `@Destructive()`: отмена заказа (`POST orders/:id/cancel`),
  откат оплаты плана (`POST planning/planned/:id/revert`).

Остальное (создание, правка, закрытие заказа, возврат в работу, проведение
«Входящих» и его отмена) оператору доступно. Роль `VIEWER` — только чтение,
`ADMIN` = владелец; обе пока никому не выдаются.

## Настройка на проде

```bash
# хэш пароля (bcrypt), в каталоге apps/api
node -e "require('bcryptjs').hash(process.argv[1],10).then(console.log)" 'пароль-оператора'
```

В `/srv/construct-v6/.env.production`: `OPERATOR_PASSWORD_HASH=<хэш>` и `2` в
`TELEGRAM_ALLOWED_IDS` (как `1` для владельца). Без `2` в allowlist вход
оператора отвечает 403.

**Грабли:** Docker Compose интерполирует `$имя` внутри значений env-файла —
куски bcrypt-хэша после `$` он считает переменными и обнуляет (в контейнере
приходит обрезанный хэш, вход отвечает «Неверный пароль», в логах `up -d` —
`The "…" variable is not set`). Каждый `$` в хэше пишется как `$$`:

```bash
node -e "require('bcryptjs').hash(process.argv[1],10).then(h=>console.log(h.replace(/\$/g,'\$\$')))" 'пароль'
```

Переменные читаются при создании контейнера: после правки `.env.production`
нужен `docker compose -f deploy/docker-compose.prod.yml --env-file .env.production up -d api`
(обычный `restart` оставит старое окружение); следующий деплой делает то же сам.

## На web

`useRole()` (`hooks/useRole.ts`) отдаёт роль текущего пространства и
`canDelete`; `navGroupsFor(role)` (`components/layout/nav-items.ts`) режет меню,
палитру и вкладки отчётов; `RoleGate` в каркасе закрывает прямые адреса.
Кнопки «Удалить»/«Отменить» у оператора не рисуются — но правило держит
сервер, а не кнопка.
